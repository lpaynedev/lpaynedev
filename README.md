## Latest release: LLM Tool Calling Lab

I built a local chatbot that selects and compares numerical ML tools, records their evidence, and lets developers replace the specialists. The first release, **v0.1.0**, is experimental and includes a frozen evaluation across four task families.

[Read the illustrated case study](https://lukepayne.web.app/lab/llm-tool-calling-lab-first-release/) · [Source and setup](https://github.com/Dolvido/llm-tool-calling-lab) · [Download v0.1.0](https://github.com/Dolvido/llm-tool-calling-lab/releases/tag/v0.1.0)

The first pass found **33/48 grounded completions for generic tool calling and 31/48 with structured planning**. Added planning instructions did not improve measured completion. Results concern synthetic data and unblinded AI review.

My direction is inspectable local AI: validated execution, replaceable models, and explanations tied to recorded evidence. The next proposed work targets anomaly answers, unsupported requests, and evidence-supported next actions. [Vision and priorities](https://github.com/Dolvido/llm-tool-calling-lab/blob/main/docs/VISION.md).
